# Test fixtures

Synthetic fixtures (`synthetic_garmin.fit/json`, generated by `python3 test/make_fit.py`) are included.
The owner's personal exports used by `test_importers.mjs`, `ui_smoke.mjs` and `ui_flows.mjs` are **not** committed (they are physiological data):
`fatmaxxer_rr_121156.csv`, `fatmaxxer_rr_123618.csv`, `fatmaxxer_features_0926.csv`, `trainred_session.csv`, `trainred_sensor0.fit`.
Copy any FatMaxxer `rr.csv` / `features.csv` and a Train.Red session CSV / sensor FIT into this folder under those names to run the full suite.
